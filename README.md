# Project: Applications for Forecasting Electricity Consumption in Metropolitan France excluding Corsica

The purpose of this Time Series project is to implement applications that are able to forecast the daily and monthly national electricity consumption in metropolitan France excluding Corsica. The goal is to identify and analyse trends, significant variations, or irregularities in consumption data in order to anticipate energy needs.

The Machine Learning models tested were trained on datasets hosted on the platform [Open Data Réseaux Énergies (ODRÉ)](https://opendata.reseaux-energies.fr/)



# Projet : Applications de prévisions de la consommation d'électricité en France métropolitaine hors Corse

Ce projet de séries temporelles vise à développer des applications capables de prévoir la consommation nationale quotidienne et mensuelle d’électricité en France métropolitaine hors Corse. L’objectif est d’identifier et d’analyser les tendances, les variations significatives ou les irrégularités dans les données de consommation, afin d’anticiper les besoins énergétiques.

Les modèles d'apprentissage automatique testés sont entraînés sur des jeux de données qui se trouvent sur la platreforme d'[Open Data Réseaux Énergies (ODRÉ)](https://opendata.reseaux-energies.fr/)
